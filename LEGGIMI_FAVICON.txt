MECENATE v3.4 — FAVICON

Questa versione aggiunge un'icona minimale:
- fondo nero
- M bianca
- coerente con il linguaggio editoriale del sito

File aggiunti:
favicon.ico
favicon-32x32.png
apple-touch-icon.png
icon-192.png
icon-512.png
site.webmanifest

INSTALLAZIONE:
Sostituisci i file HTML e aggiungi tutti i nuovi file icona nella cartella principale del sito.
Poi:
git add .
git commit -m "Add Mecenate favicon"
git push

NOTA:
Safari può mostrare la vecchia icona per cache. Dopo il deploy:
- chiudi la scheda
- riapri il sito
- oppure usa una finestra privata
- Google può impiegare alcuni giorni ad aggiornare l'icona nei risultati.
