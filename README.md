# MECENATE 01

Prima ricostruzione completa del sito di Mecenate Studio.

## Avvio
Aprire `index.html` nel browser oppure pubblicare l’intera cartella su Vercel, Netlify o GitHub Pages.

## Struttura
- `index.html`: home
- `work.html`: indice dei progetti
- `film.html`, `digital-spaces.html`, `creative-direction.html`: pagine editoriali
- `studio.html`, `journal.html`, `contact.html`
- `assets/css/main.css`: sistema visivo completo
- `assets/js/main.js`: menu, reveal, nota editoriale

## Sostituire i media
Le aree fotografiche sono volutamente astratte. Sostituire i gradienti nelle classi `.media-film`, `.media-digital`, `.media-direction`, `.studio-page__portrait`, `.gallery-block` e `.detail-hero__media` con immagini reali tramite `background-image`.

## Contatto
L’indirizzo attuale è `studio@mecenatestudio.com`. Modificarlo in `contact.html` qualora necessario.

## Principi
Nessuna dipendenza esterna, mobile-first, accessibilità di base, animazioni native e supporto a `prefers-reduced-motion`.
