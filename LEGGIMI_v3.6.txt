MECENATE v3.6 — CONTINUAZIONE FOTOGRAFICA + LINGUE + CONTATTI PRIVATI

COSA CAMBIA
1. La sezione Gilbert usa due copie della stessa fotografia, perfettamente allineate:
   - il rettangolo è nitido;
   - tutto ciò che lo circonda è la continuazione esatta della stessa immagine, sfocata.
2. Selettore lingua globale:
   - IT
   - EN
   - ES
   La scelta viene ricordata dal browser.
3. Email e telefono non sono più mostrati in chiaro.
   Restano disponibili soltanto tramite i pulsanti:
   - Scrivici
   - Chiamaci
4. Il layout mobile è incluso.

INSTALLAZIONE
Sostituisci tutti i file nella cartella:
~/Documents/mecenate-studio-v2

Poi esegui:
cd ~/Documents/mecenate-studio-v2
git add .
git commit -m "Add multilingual studio continuity section"
git push

NOTA
